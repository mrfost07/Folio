# Security Policy

---

### Supported versions

Only the latest published release receives security fixes. Please check [Releases](https://github.com/mrfost07/Folio/releases) before reporting.

### Reporting a vulnerability

Please do **not** open a public issue for security problems. Instead:

1. Use GitHub's private vulnerability reporting: [Report a vulnerability](https://github.com/mrfost07/Folio/security/advisories/new).
2. Or email: **mfostanes@ssct.edu.ph** with `[Folio security]` in the subject.

Include what you found, how it could affect users, and reproduction steps if available. You will receive an acknowledgment within 7 days. Fixes ship in the next regular release unless the issue is critical.

### Scope notes

Folio is a local desktop application: it does not operate servers or process other users' data. Reports about the application itself, its installer, updater, or the optional WebDAV cloud-backup client flow are all in scope.
