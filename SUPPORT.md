# Support

---

## English

| I want to… | Where to go |
| --- | --- |
| Report a bug | The in-app **Feedback** entry (can attach a privacy-filtered diagnostics package — fastest path to a fix), or [GitHub Issues](https://github.com/mrfost07/Folio/issues) |
| Suggest a feature / ask how something works | [GitHub Discussions](https://github.com/mrfost07/Folio/discussions) |
| Read guides and answers | The [wiki](https://github.com/mrfost07/Folio/wiki) and [README](README.md) |
| Report a security problem | See [SECURITY.md](SECURITY.md) — private channels only |
| Download the latest version | [Releases](https://github.com/mrfost07/Folio/releases) or [folio.fun](https://folio.fun) |

Folio is maintained by a solo developer; please allow time for replies. Commercial support is not offered.
